# ---- PyTorch (CUDA 构建, 供 gliner / mineru / DeepKE / spaCy-transformer 使用 GPU) ----
# 必须显式 pin 到 +cu124 本地版本: 否则 pip 会优先选 PyPI 上的 CPU 版 torch, GPU 失效
# 注意: torch 必须 >=2.6，因为 mineru 3.x 要求 torch>=2.6（其 pipeline/vlm extra 显式约束）。
# 若降到 2.3，mineru 解析会回退到旧的 magic-pdf 线并强制 scipy==1.9.1，导致构建冲突/源码编译失败。
# 重要: PyTorch 自 2.6.0 起不再发布 +cu121 wheel（cu121 只到 2.5.1），故这里用 +cu124。
# +cu124 要求宿主机 NVIDIA 驱动 >= 550（T4 配较新驱动即可）；如驱动较旧请改用 +cu121 + torch==2.5.1 组合
# （但会违反 mineru 的 torch>=2.6 约束，需同步降级 mineru）。
